## 2. What consumer is actually missing?

Add one diagnostic line before all those gates:

        kind={pixel|composite|present} result={native|no_alias|range_miss|

## 3. A/B and generations

Use two identities:

- Storage identity: `{full src_rt_key, generation/slot}`.
- Guest alias identity: `{dest base/range, format, pitch, extent, endian/swizzle}`.

Do not key the storage itself by `1CA1C000` or `1CDB4000`. At the current resolve, alias whichever base is actually written to the completed producer generation.

The existing persistent map cannot do this: it overwrites one edge per source RT and is queried before the current resolve ([vulkan_command_processor.h:1794](<C:/Users/leanerdesigner/Documents/New project 8/xenia-thor/src/xenia/gpu/vulkan/vulkan_command_processor.h:1794>), [vulkan_command_processor.cc:4420](<C:/Users/leanerdesigner/Documents/New project 8/xenia-thor/src/xenia/gpu/vulkan/vulkan_command_processor.cc:4420>)).

Minimum state:

```text
generation_id
src_rt_key
write_scheduled_sequence
sample_ready_sequence
publish_copy_sequence
publish_frame_epoch
content_extent
format / samples / swizzle
layout
last_use_submission
```

Checks:

- Sampler redirect: alias exists; referenced generation is still resident and ready; publish precedes this draw; full descriptor is compatible.
- Present redirect: same checks, plus alias guest base exactly equals the current swap base and was published in the current BD frame epoch.
- Starting another write into the same image invalidates older aliases unless a new slot is acquired.
- `rendered_this_frame` remains only a clear/load policy. It must not be content validity; it is reset after present and is set before useful pixels are independently proven ([vulkan_command_processor.cc:3465](<C:/Users/leanerdesigner/Documents/New project 8/xenia-thor/src/xenia/gpu/vulkan/vulkan_command_processor.cc:3465>)).

Also, the current “safe” gate is not actually wired to consumer proof. The header describes prior-frame consumer bits, but `BdNativeSurfaceServes` only checks aux enabled plus a non-null layout-valid view ([vulkan_command_processor.h:843](<C:/Users/leanerdesigner/Documents/New project 8/xenia-thor/src/xenia/gpu/vulkan/vulkan_command_processor.h:843>), [vulkan_command_processor.cc:8467](<C:/Users/leanerdesigner/Documents/New project 8/xenia-thor/src/xenia/gpu/vulkan/vulkan_command_processor.cc:8467>)). Do not enable current drops immediately after bridging.

Split the predicate into:

- `CanSkipOwnershipImport(dest_rt, current producer)` — native already has prior content, or the pass is proven load-dead.
- `CanSkipResolve(resolve_info, published generation)` — current destination alias is ready and consumers are covered.

## 4. Minimal one-drop sequence

Convert the final 1280 composite first, not field/471. It is the graph leaf: one expected external consumer, present. Field/471 fans out into bloom/composite reads and has partial accumulation, making it a worse first proof.

1. Target the producer whose following current resolve destination is exactly `1CA1C000` or `1CDB4000`. Do not use only the `9567…` PS hash—the current boolean matches every draw with that hash ([vulkan_command_processor.cc:5950](<C:/Users/leanerdesigner/Documents/New project 8/xenia-thor/src/xenia/gpu/vulkan/vulkan_command_processor.cc:5950>)).
